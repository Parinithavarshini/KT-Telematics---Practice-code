Javascript runtime flow
    Open tab,js engine creates a window object this is global object
    It stores browser related things
    Document object-property inside window object - html file will load here
DOM Tree 
    While loading html each node is stored in tree like structure
    After creating tree structure we can manipulate it using JS(change,style,event)
Browser environment - Javascript_browser extra objects
    *window-alert,fetch,setTimeOut,SetInterval
    *document-represents full html page and change using it
        document.title="new";
        document.body.style.background = "yellow";
    *location - Current page URL details
        console.log(location.href);      //full url
        location.reload();  
    *navigator - User browser & device info
        console.log(navigator.userAgent);
        console.log(navigator.onLine); 
        console.log(navigator.language); 
    *history - track User visited pages
        history.back();   
        history.forward(); 
        console.log(history.length);
